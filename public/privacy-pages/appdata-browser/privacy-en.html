appDataFolder Browser

Privacy Policy

Last updated: October 2026

Summary: appDataFolder Browser runs entirely in your browser. It does not send your data to StellaSecret servers — there are none. It accesses Google Drive only when you sign in, and the access token stays in your browser tab's memory.

1. Who we are

appDataFolder Browser is a free, open-source web tool for viewing, downloading and deleting revisions of files in Google Drive's hidden appDataFolder. It is published by StellaSecret as a personal project and is not operated by a commercial entity. The source code is available on GitHub.

2. Data processed

The tool reads only the files and revisions in the appDataFolder that the signed-in OAuth application is allowed to access. Depending on the actions you take:

  • Listing: file and revision metadata is read from Google Drive and displayed in your browser.
  • Download: the selected file content is downloaded directly to your device.
  • Delete: the selected revisions are permanently deleted from Google Drive.

All operations happen directly between your browser and Google's APIs. No data is routed through, or stored on, a server operated by StellaSecret.

3. Google authentication

Sign-in uses Google Identity Services and OAuth 2.0 with the drive.appdata scope. This scope only grants access to the requesting OAuth application's own hidden folder; it cannot access the rest of your Google Drive.

The OAuth Client ID is a public identifier, not a secret. The access token is short-lived and kept only in your browser tab's memory. No refresh token is requested. You can revoke access at any time from Google Account → Third-party apps.

4. Data stored locally

Only the non-secret OAuth Client ID is saved in your browser's localStorage, so you do not have to paste it again on your next visit.

✓ No access token or refresh token is stored in localStorage.
✓ No file content or revision history is stored by the tool.
✓ Clearing your browser storage removes the saved Client ID.

5. Advertising and analytics

appDataFolder Browser contains no advertising, no analytics, and no tracking cookies.

6. Third-party services

  • Google Drive API and Google Identity Services: subject to Google's privacy policy.
  • GitHub Pages: hosts the application. GitHub may process technical connection data as described in the GitHub Privacy Statement.

7. Data retention and deletion

StellaSecret retains no data from this tool. Deleting a revision is permanent — Google Drive's appDataFolder has no trash — so download anything you want to keep first. To remove the locally saved Client ID, clear the site's data in your browser.

8. Contact

For any questions regarding this privacy policy: contact@stellasecret.com
