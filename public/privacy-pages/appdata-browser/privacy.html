appDataFolder Browser

Politique de confidentialité

Dernière mise à jour : octobre 2026

En résumé : appDataFolder Browser fonctionne entièrement dans votre navigateur. Il n'envoie aucune donnée aux serveurs de StellaSecret — il n'y en a pas. Il accède à Google Drive uniquement lorsque vous vous connectez, et le jeton d'accès reste en mémoire dans l'onglet du navigateur.

1. Qui sommes-nous ?

appDataFolder Browser est un outil web gratuit et open source permettant de consulter, télécharger et supprimer les révisions des fichiers du dossier appDataFolder caché de Google Drive. Il est publié par StellaSecret à titre personnel et n'est pas exploité par une société commerciale. Le code source est disponible sur GitHub.

2. Données traitées

L'outil lit uniquement les fichiers et révisions du dossier appDataFolder auxquels l'application OAuth connectée est autorisée à accéder. Selon vos actions :

  • Consultation : les métadonnées des fichiers et révisions sont lues depuis Google Drive et affichées dans votre navigateur.
  • Téléchargement : le contenu du fichier sélectionné est téléchargé directement sur votre appareil.
  • Suppression : les révisions sélectionnées sont définitivement supprimées de Google Drive.

Toutes les opérations se font directement entre votre navigateur et les API de Google. Aucune donnée ne transite par un serveur exploité par StellaSecret, ni n'y est stockée.

3. Authentification Google

La connexion utilise Google Identity Services et OAuth 2.0 avec le scope drive.appdata. Ce scope donne uniquement accès au dossier caché de l'application OAuth demandeuse ; il ne permet pas d'accéder au reste de votre Google Drive.

Le Client ID OAuth est un identifiant public, pas un secret. Le jeton d'accès est de courte durée et conservé uniquement en mémoire dans l'onglet du navigateur. Aucun jeton de rafraîchissement n'est demandé. Vous pouvez révoquer l'accès à tout moment depuis Compte Google → Applications tierces.

4. Données stockées localement

Seul le Client ID OAuth, qui n'est pas secret, est enregistré dans le localStorage de votre navigateur, afin de ne pas avoir à le coller à chaque visite.

✓ Aucun jeton d'accès ni jeton de rafraîchissement n'est stocké dans le localStorage.
✓ Aucun contenu de fichier ni historique de révisions n'est conservé par l'outil.
✓ Effacer les données du site dans votre navigateur supprime le Client ID enregistré.

5. Publicité et analyse d'audience

appDataFolder Browser ne contient aucune publicité, aucun outil d'analyse et aucun cookie de suivi.

6. Services tiers

  • Google Drive API et Google Identity Services : soumis à la politique de confidentialité de Google.
  • GitHub Pages : héberge l'application. GitHub peut traiter des données techniques de connexion comme décrit dans la déclaration de confidentialité de GitHub.

7. Conservation et suppression des données

StellaSecret ne conserve aucune donnée issue de cet outil. La suppression d'une révision est définitive — le dossier appDataFolder de Google Drive n'a pas de corbeille — pensez donc à télécharger ce que vous souhaitez conserver. Pour supprimer le Client ID enregistré localement, effacez les données du site dans votre navigateur.

8. Contact

Pour toute question concernant cette politique de confidentialité : contact@stellasecret.com
